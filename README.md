# andrewbiernat.ai

Andrew Biernat's personal site. A single static page.

## Editing

The whole site is `index.html`. Edit it in any text editor, commit, and push. Cloudflare Pages rebuilds and deploys on every push to `main`.

## Deploy

- Live at https://andrewbiernat.ai
- Also at https://andrew-biernat.pages.dev
- Cloudflare Pages project: `andrew-biernat`
- No build step. The file is served as-is.
